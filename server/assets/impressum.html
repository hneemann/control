Erhebung von Daten beim Besuch dieser Website

Es werden keinerlei personenbezogenen Daten erhoben, gespeichert oder weitergegeben. Es werden keine IP-Adressen gespeichert. Es werden keine Daten an Dritte weitergegeben. Die Authentifizierung des Nutzers erfolgt über den zentralen Identitätsdienst der DHBW-Mosbach. Es wird ein technisch erforderliches Session-Cookie gesetzt, welches nach Beendigung der Session verworfen wird. Ein Tracking oder eine Analyse des Nutzerverhaltens findet nicht statt.

Die Ausführung der vom Nutzer eingegebenen Skripte findet im Browser des Nutzers statt. Diese verlassen den Browser dafür nicht.

Dem Nutzer steht jedoch eine Speichern-Funktion zur Verfügung: Der Nutzer kann so seine Skripte auf dem Server speichern, wenn er diese Speichern-Funktion verwendet. Der Nutzer kann seine gespeicherten Skripte jederzeit einsehen, bearbeiten oder löschen.

Alle Skripte werden 180 Tage nach der letzten Anmeldung des Nutzers automatisch gelöscht.
